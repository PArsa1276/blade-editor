# مربی سه‌بعدی شکم (Abs Trainer 3D)

وب‌اپلیکیشن محلی برای یادگیری و انجام ۹ حرکت شکم از ویدیوی تمرینی، با مدل سه‌بعدی.

## اجرا (لوکال)

پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر.

```bash
cd abs-trainer-3d
npm install
npm run dev
```

سپس در مرورگر باز کن: http://localhost:5173

> با `--host` اجرا می‌شود؛ پس از گوشی در همان شبکه Wi‑Fi هم با آدرس IP کامپیوتر باز می‌شود (مثلاً `http://192.168.1.10:5173`).

نسخه نهایی بدون سرور توسعه:

```bash
npm run build
npm run preview
```

## امکانات

- مدل سه‌بعدی: با ماوس یا انگشت بچرخان و زوم کن. دکمه‌های دوربین: جلو، بغل، ۴۵°، بالا، چرخش خودکار.
- کنترل حرکت: پخش/توقف (Space)، مرحله قبل/بعد (کلیدهای جهت)، نوار زمان، سرعت ۰.۲۵× تا ۱.۲۵×.
- نام هر مرحله روی صفحه، و نوار «فشار روی شکم».
- نمایش «شبح»: حالت شروع (آبی) و اوج حرکت (نارنجی) کنار هم.
- عضله فعال روی مدل رنگی می‌شود.
- برای حرکت‌های «هر طرف»: دکمه عوض کردن طرف.
- حالت «شروع تمرین کامل»: شمارش معکوس، شمارش تکرار یا زمان، استراحت بین ست‌ها و صدای بوق.
  تعداد ست و زمان استراحت قابل تنظیم است.
- مقایسه با ویدیوی اصلی: فایل ویدیو را انتخاب کن؛ بخش هر حرکت کنار مدل پخش می‌شود
  (فایل فقط در مرورگر خودت باز می‌شود و جایی آپلود نمی‌شود).

## ساختار کد

- `src/figure.js` — ساخت آدمک سه‌بعدی و اعمال زاویه مفصل‌ها
- `src/exercises.js` — داده حرکت‌ها: فریم‌های کلیدی، مراحل، نکته‌ها
- `src/main.js` — صحنه، کنترل‌ها و حالت تمرین

برای تغییر یک حرکت، زاویه‌های `keys` در `src/exercises.js` را عوض کن.
