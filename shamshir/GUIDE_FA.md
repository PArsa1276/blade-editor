# راهنمای شمشیر (برای کسی که تازه شروع می‌کند)

شمشیر یک ابزار ادیت ویدیو برای هوش مصنوعی است. شما فقط به زبان ساده می‌گویید چه می‌خواهید؛
هوش مصنوعی با ابزارهای شمشیر ویدیو را می‌بیند، تحلیل می‌کند، ادیت می‌کند و خروجی را بررسی می‌کند.
همه چیز روی کامپیوتر خودتان و رایگان است.

## ۱. نصب (یک بار)

۱. پایتون ۳.۱۰ یا جدیدتر و ffmpeg را نصب کنید.
۲. در پوشهٔ `shamshir` این دستور را اجرا کنید:
```
pip install -e ".[captions]"
```
۳. شمشیر را به Claude Code وصل کنید:
```
claude mcp add --scope user shamshir -- shamshir
```
۴. (پیشنهاد) مهارت ادیت را نصب کنید تا هوش مصنوعی بهترین روش را بداند:
```
mkdir -p ~/.claude/skills && cp -r skill/shamshir-edit ~/.claude/skills/
```
۵. Claude Code را یک بار ببندید و دوباره باز کنید.

## ۲. فایل‌ها را آماده کنید

- همهٔ کلیپ‌ها، موزیک و ویدیوی مرجع را در یک پوشه بگذارید.
- اسم فایل‌ها را ساده بگذارید (مثلاً `clip1.mp4`، `song.mp3`، `ref.mp4`).
- کلیپ‌های باکیفیت و پرحرکت نتیجهٔ بهتری می‌دهند. ۳ تا ۱۰ کلیپ برای یک ادیت ۱۵ ثانیه‌ای کافی است.

## ۳. چه بگوییم؟ (نمونه)

- «با کلیپ‌های پوشهٔ `~/videos/trip` و موزیک `song.mp3` یک ادیت ۱۵ ثانیه‌ای عمودی hype بساز. اول عنوان «سفر» بیاید.»
- «ویدیوی `ref.mp4` را تحلیل کن و با کلیپ‌های من یک ادیت با همان ریتم و حس بساز. بعد با مرجع مقایسه کن.»
- «از ویدیوی `talk.mp4` مکث‌ها را حذف کن، زیرنویس فارسی کلمه به کلمه بگذار و عمودی‌اش کن.»
- «لوگوی `logo.png` را گوشهٔ بالا راست بگذار و حجم فایل زیر ۵۰ مگابایت باشد.»

## ۴. برای بهترین نتیجه

- **مرجع بدهید:** یک ویدیوی نمونه که سبکش را دوست دارید، بهترین راهنماست.
- **مدت و قطع را بگویید:** مثلاً «۱۵ ثانیه، ۹:۱۶ برای اینستاگرام».
- **قدم به قدم اصلاح کنید:** «کات‌ها سریع‌تر»، «فلش کمتر»، «در ثانیهٔ ۸ اسلوموشن بگذار». تغییرهای کوچک سریع رندر می‌شوند.
- **لرزش‌گیر و ایموجی:** «کلیپ ۲ را لرزش‌گیر کن»، «کنار متن ایموجی 🔥 بگذار» هم کار می‌کند.
- **پیش‌نمایش بخواهید:** «اول پیش‌نمایش را نشانم بده».

## ۵. سبک‌های آماده

| سبک | حس |
|---|---|
| hype | کات روی هر بیت، زوم پانچ، فلش، لرزش |
| phonk | سیاه‌وسفید پرکنتراست، لرزش و فلش زیاد |
| cinematic | کات آرام، فید، زوم آرام، لترباکس، رنگ سینمایی |
| smooth | آرام و گرم |
| glitch | گلیچ و رنگ سایبری |

## ۶. ساخت ویدیو با گوگل فلو (اختیاری)

۱. نصب: `pip install -e ".[flow]"`
۲. به هوش مصنوعی بگویید: «flow_setup را اجرا کن» و دستوری را که می‌دهد اجرا کنید. یک Chrome جدا باز می‌شود.
۳. در آن Chrome با حساب گوگل خودتان وارد شوید و یک پروژه در Flow باز کنید.
۴. بگویید: «با فلو یک کلیپ از ... بساز و در ادیت بگذار».
   اول فقط پرامپت تایپ می‌شود و اسکرین‌شات می‌بینید (اعتباری خرج نمی‌شود). بعد از تأیید شما ساخته می‌شود.
- اعتبار خود شما خرج می‌شود. اگر فلو پنجرهٔ تأیید اعتبار نشان داد، خودتان در مرورگر تأیید کنید.
- خودکارسازی سایت فلو ممکن است خلاف قوانین گوگل باشد؛ مسئولیت با خودتان است. اگر گوگل ظاهر سایت را عوض کند، ممکن است کار نکند.

## ۷. محدودیت‌ها (صادقانه)

- شمشیر خودش صحنهٔ جدید نمی‌سازد؛ برای ساخت صحنه از گوگل فلو با حساب خودتان استفاده می‌کند.
- موشن‌گرافیک‌های پیچیدهٔ افترافکت (ماسک، متن سه‌بعدی ردیابی‌شده، پارتیکل) را کپی نمی‌کند؛ ریتم، فلش، لرزش، زوم، رنگ، سرعت و متن را نزدیک به مرجع می‌سازد.
- زیرنویس خودکار به بستهٔ `faster-whisper` نیاز دارد (با `[captions]` نصب می‌شود).
